# FlexiSpot AI 虚拟创作者品牌合作企划 · 全景分析与技术可行性报告

宁波诺丁汉大学商学院（中国）× 乐歌 FlexiSpot 商业竞赛 · 课题二参赛工作仓库

## 项目简介

本仓库收录 FlexiSpot 商赛**课题二「AI 虚拟创作者的品牌合作企划」**的全景分析与技术可行性研究报告。报告面向 FlexiSpot 原创虚拟创作者（AI Virtual Creator）的可行性与策略，覆盖赛事解析、行业与案例研究、2026 年全流程技术工具链、合规标注、风险与竞赛策略，以及长期 IP 运营等发散维度，是后续正式 Proposal 的作战地图。

## 核心结论

1. **战略判断**：课题二是三个课题中差异化空间最大、与企业战略契合度最高的方向；海外家居/升降桌 DTC 赛道尚无标志性虚拟人，存在抢占「第一个做虚拟人的升降桌品牌」的空白机会。
2. **技术可行性**：2026 年商科学生团队 2 周可跑通 MVP（约 ¥130–180/项目），3–5 人 3–4 周可交付完整提案；最大真实成本是废片率（按工具标价 ×3–5 预算）。
3. **工具链**：MVP 档为即梦 Seedream + Seedance + 对口型 + ElevenLabs + CapCut；进阶档为 Midjourney + 可灵 Kling + Veo + HeyGen + Suno。
4. **合规是生死线**：须按 FTC、欧盟 AI Act、中国生成式 AI 标识办法及 TikTok/Instagram/YouTube 平台规则完成双层披露（广告身份 + AI 身份）。
5. **最直接对标案例**：IKEA × Imma 原宿（2020）虚拟人生活方式营销。
